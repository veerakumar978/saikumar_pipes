# SAAIKUMAR Valves & Cocks

Official responsive business website for **SAAIKUMAR Valves & Cocks**, premier supplier of plumbing, piping, valves, sanitaryware, water storage tanks, and borehole solutions based in Rajamahendravaram, Andhra Pradesh, India.

---

## 🌟 Features

- **Full-Width Hero Section**: Premium plumbing showcase with high-contrast light typography overlay and quick action buttons.
- **Trust Strip**: Core business strengths highlighting quality-checked stock, genuine brands, retail/wholesale counters, and technical guidance.
- **About Us**: Dedicated showcase of commercial plumbing and sanitary product categories.
- **Interactive Product Categories**: CPVC, UPVC, PVC, Electrical Conduits, Sanitaryware, Water Storage Tanks, and PVC Borewell Casing Pipes with specifications and WhatsApp enquiry links.
- **Official Brand Range**: Authentic brand showcase featuring Ashirvad by Aliaxis, Trubore, Watertec, Onida Ibibo, Leo, L&K Supremo, Ideal, HP Adhesives, Jindal Vignec, Somany, Anchor, and Toy.
- **Why Choose Us**: Value propositions detailing direct sourcing, diverse sizing, commercial-grade plumbing hardware, and prompt fulfillment.
- **Our Store & Google Maps**: Authentic storefront photograph, verified physical address in Rajamahendravaram, and direct "View Location" & "Get Directions" Google Maps actions.
- **Interactive Enquiry Form**: Live form validation, Indian phone format checking, structured WhatsApp handoff, and accessible confirmation modal dialog.
- **Responsive Across All Breakpoints**: Zero horizontal overflow verified across 320px to 1920px viewports.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite 6](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

### Prerequisites

Ensure you have Node.js (v18+) installed.

### Installation

```bash
# Clone the repository
git clone https://github.com/veerakumar978/saikumar_pipes.git

# Navigate to project directory
cd saikumar_pipes

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
